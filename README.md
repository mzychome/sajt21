# Flatfolio

A responsive flat comparison notebook. Add, edit, delete, search, and sort properties. Price per square metre is calculated from size and total price. Prices use PLN. Entries are saved in browser localStorage, scoped to the browser and site address; there is no server database or account system.

## Run

Requires Python 3 and optionally Node.js for the syntax check. No dependency installation is needed.

```sh
cd /workspace/sajt
npm start
```

The server listens on port 3000. To check JavaScript syntax, run `npm run check`.
